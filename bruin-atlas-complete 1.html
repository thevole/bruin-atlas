Explicit Ownership Areas

🎯 Data Trust & Confidence Ownership (CRITICAL)

Atlas lives or dies on data credibility. This team owns trust end-to-end.

  • Confidence Markers: Tag all data as verified, inferred, or stale
  • Freshness Indicators: Display "last updated" for every data point
  • Import Quality: Flag low-confidence imports with remediation steps
  • "We Don't Know" States: Explicitly show when data is missing vs. unavailable
  • Data Integrity: Detect and surface anomalies

If users don't trust Atlas data, nothing else matters. This is truth management.

Data Trust Framework

Confidence Levels

  • Verified (High): Direct API query within freshness threshold
  • Inferred (Medium): Derived from related data or historical patterns
  • Stale (Low): Data older than threshold, may be outdated
  • Unknown (None): No data available, never queried, or API failed

Freshness Thresholds

  • Critical Device Status: 15min (routers, core switches)
  • Standard Device Status: 30min (access switches, APs)
  • Incidents: Real-time (<5 seconds)
  • Health Scores: 30min (recalculated on data refresh)
